# 🏃 Unity 2D Parkour Game

**A 2D platformer with points, two stages, traps and a finish line**

![Unity](https://img.shields.io/badge/Unity-000000?style=for-the-badge&logo=unity&logoColor=white) ![C#](https://img.shields.io/badge/C#-239120?style=for-the-badge&logo=csharp&logoColor=white)

</div>

---

## ✨ Features

- Parkour-style platforming
- Point collecting
- 2 stages with a finish line
- Traps: spikes, saws and maces
- Mobile joystick controls
- Android APK build

## 🚀 Getting Started

1. Open the project with **Unity 2021.3.5f1** via Unity Hub.
2. Load a scene and press **Play**.
3. Or install the built Android APK on your device.
